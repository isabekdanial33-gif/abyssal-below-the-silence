# ABYSSAL: BELOW THE SILENCE

Психологический survival horror на Three.js. Комплекс NADIR-9, 2041 год, глубина 1,8 км.

## Запуск
- **Онлайн:** https://abyssal-below-the-silence.vercel.app
- **Windows (.exe):** `release/ABYSSAL-win32-x64/ABYSSAL.exe`
- **Разработка:** `npm install` → `npm run dev` → http://localhost:5173
- Сборка веба: `npm run build` (папка `dist`). Сборка exe: `npm run build`, затем
  `npx @electron/packager . ABYSSAL --platform=win32 --arch=x64 --out=release --overwrite --asar --ignore="^/(src|public|tools|release)" --ignore="^/node_modules"`
- Проверка карт: `npm run check`

## Управление
WASD — ходьба, мышь — обзор, Shift — бег, Ctrl/C — присед, Space — прыжок, E — действие,
F/1 — фонарь, 2/H — аптечка, 3/B — батарея, Tab/I — инвентарь, J — журнал, Q/R — наклон,
ЛКМ с предметом: щелчок — уронить, удержание — бросок (сила растёт), G — положить, F1 — помощь, Esc — пауза.

## Содержание
6 глав, 10 зон (лифтовой узел, техтоннели, жилой блок, лаборатории, метро, гидрокомплекс,
разлом, нижний архив, ядро), 10 головоломок, 4 концовки, существо «Эхо» с ИИ из 9 состояний,
процедурный звук и музыка, субтитры, сохранения, настройки, журнал со схемой и хронологией.

## Ассеты и лицензии
Все текстуры, модели окружения, звуки и музыка — процедурные (сгенерированы кодом).
Модель ног игрока — `Soldier.glb` из примеров three.js (персонаж Mixamo, разрешён к использованию в проектах).
Three.js — MIT. Голоса — синтетические (синтез речи браузера / формантный синтез), не человеческая озвучка;
настоящие записи подключаются через `public/audio/vo/manifest.json`.
